# greenden-tailwind

🌱 A responsive Greenden website built using HTML, Tailwind CSS, and JavaScript, inspired by a modern plant and flower website. This project focuses on practicing Tailwind CSS, responsive layouts, interactive elements, plant product sections, customer reviews, and clean UI design.

## 📌 About the Project

This project is a Greenden Plant Website created using HTML, Tailwind CSS, and JavaScript. The main purpose of this project is to practice and improve my frontend web development skills by building a modern, responsive, and visually appealing plant-themed website.

This project helped me gain hands-on experience in using Tailwind CSS utility classes, creating responsive layouts, and building interactive website components.

## 🎯 Purpose

This project was developed as a frontend practice project while learning Tailwind CSS. It helped me understand utility-first CSS, responsive design, layouts, spacing, typography, flexbox, and how to build a complete and modern website using Tailwind CSS.

It also helped me improve my understanding of combining HTML, Tailwind CSS, and JavaScript to create a responsive and interactive user interface.
